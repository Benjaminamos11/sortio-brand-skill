# Sortio explainer skeleton (16:9, 60–180 s, HyperFrames)

Script → `lines.json` → ElevenLabs voice with word timings → subtitles and caption chunks → HyperFrames composition timed to the spoken words → mix at −14 LUFS → render → thumbnail and YouTube text. The full method and the reasons are in `../../references/explainer-videos.md`; this file is the command sheet.

Tested end to end on 20 Nov 2026 (HyperFrames 0.9.70): draft voice → subtitles → mix → `check` (0 errors) → render (82.6 s, 1920×1080, about 22 s render time) → thumbnail; the ElevenLabs path was tested with two short lines (model `eleven_v4`).

## Files

| File | What it is |
|---|---|
| `script-template.md` | Beat sheet to fill in and get approved before anything is recorded |
| `lines.json` | The voice-over, one object per line: `text` (subtitles), optional `say` (spoken form of numbers), `pause`, `scene`, optional `chapter` and `keys` |
| `scenes.js` | What each scene shows (`title`, `phone`, `points`, `end`) and the cue words that trigger screens, callouts, rings and cards. A cue is `[line index in lines.json, "word"]` (first line = 0) |
| `index.html` | The HyperFrames composition (layout and motion). Rarely edited |
| `vo-data.js` | Generated by `tools/build_subtitles.py`; the shipped one comes from a draft voice of the sample script |
| `thumb.html` | YouTube thumbnail (1280×720) |
| `tools/vo_elevenlabs.py` | Voice-over with word timings, or a free `--draft` placeholder |
| `tools/build_subtitles.py` | `vo/subtitles.srt`, `vo/chapters.txt`, `vo-data.js`, and the video length in `index.html` |
| `tools/mix.sh` | Voice + optional music bed (ducked) → `audio/mix.m4a` at −14 LUFS |
| `tools/finalize.sh` | Loudness check, optional poster frame, cover JPG |
| `tools/thumbnail.py` | `thumb.html` → `renders/thumbnail.jpg` (Playwright) |
| `tools/new_explainer.py` | Makes a self-contained project folder (HyperFrames cannot load the template's `../../assets/` paths) |
| `.env.example` | Copy to `.env` in the project folder and put your own ElevenLabs key in it. Never commit `.env` |

## Commands

```bash
cd ~/.claude/skills/sortio-brand/templates/explainer
python3 tools/new_explainer.py ~/Sortio-Videos/2026-11-20-explainer
cd ~/Sortio-Videos/2026-11-20-explainer
cp .env.example .env                                   # then paste your ElevenLabs key into .env

# 1. write the script (script-template.md), then lines.json and scenes.js
# 2. free timing pass
python3 tools/vo_elevenlabs.py --draft
python3 tools/build_subtitles.py
bash tools/mix.sh
npx --yes hyperframes@0.9.70 check                     # 0 errors
npx --yes hyperframes@0.9.70 preview                   # look at it; a "DRAFT VOICE" badge shows in the corner
# 3. real voice (costs ElevenLabs characters), then the same steps again
python3 tools/vo_elevenlabs.py --voice <voice_id> --stability 0.42 --similarity 0.8 --style 0.22
python3 tools/build_subtitles.py
bash tools/mix.sh audio/music.mp3                      # music optional, licensed or royalty-free only
npx --yes hyperframes@0.9.70 check
npx --yes hyperframes@0.9.70 render --output renders/explainer.mp4
bash tools/finalize.sh renders/explainer.mp4 12        # poster frame from 12 s, cover JPG
python3 tools/thumbnail.py                             # renders/thumbnail.jpg
```

Python packages: `python3 -m pip install numpy soundfile playwright && python3 -m playwright install chromium`.

## Editing tips

- **Change a few lines of the voice:** edit them in `lines.json`, run `vo_elevenlabs.py` again with the same voice and settings; only changed lines (and none of the others) are sent. Changing voice, model or settings re-records everything.
- **A cue does not fire:** the page logs `cue not found: line N, word "…"` and `check` reports it. Cue words are matched without punctuation and case; use the word as it appears in `text`, not in `say`.
- **Captions:** 32 characters per chunk for 16:9 (`--max 22` for 9:16). Key words in ember: numbers automatically, others via `"keys"` on the line.
- **Scene types:** `title` (centred headline), `phone` (headline left, phone right, callouts and a highlight ring), `points` (headline and up to three cards), `end` (dark band, logo, CTA; captions off). Consecutive `phone` scenes keep the phone on screen and push the next screen in.
- **Length:** `build_subtitles.py` writes the voice length plus `--tail` (default 3 s for the end card) into `data-duration` of `#root` and `<audio id="mix">`. Do not edit those numbers by hand.
